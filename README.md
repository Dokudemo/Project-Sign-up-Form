# Project-Sign-up-Form

The project recreates a registration page layout with a full-height image sidebar, an Odin logo banner, introductory text, and a user account creation form.

## Live Demo

[View the live project] https://dokudemo.github.io/Project-Sign-up-Form/

## Features

- Full-height two-column layout
- Image sidebar with a dark logo banner
- Odin logo and custom Norse font
- User registration form
- Required fields for first name, last name, email, phone number, password, and password confirmation
- Semantic form elements: `form`, `fieldset`, `legend`, `label`, and `input`
- Built-in HTML validation using `required` and input types such as `email`, `tel`, and `password`
- Custom input focus styles
- Button hover and active states
- Roboto font from Google Fonts
- Photo credit included in the page footer

## Built With

- HTML5
- CSS3
- Flexbox
- CSS pseudo-classes
- HTML form validation
- Google Fonts
- Git and GitHub

## What I Practiced

This project helped me practice:

- Building a structured page layout with HTML
- Using Flexbox to create columns and align form content
- Working with full-screen background images
- Using relative and absolute positioning
- Connecting `label` elements to inputs with `for` and `id`
- Creating accessible required form fields
- Styling form controls and focus states
- Using CSS pseudo-classes such as `:hover`, `:active`, and `:focus`
- Loading local fonts with `@font-face`
- Importing a font from Google Fonts
